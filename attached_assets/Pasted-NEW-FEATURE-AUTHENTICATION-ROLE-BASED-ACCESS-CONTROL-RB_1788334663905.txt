ROLE BASED ACCESS CONTROL
==================================================

Implement the following roles:

1. PRODUCTION_OPERATOR
2. QUALITY_OPERATOR
3. ENGINEERING_OPERATOR
4. STORES_OPERATOR
5. MANAGER
6. ADMIN

==================================================
ROLE PERMISSIONS
==================================================

PRODUCTION_OPERATOR

Can:

- View Production section
- Create/Edit Production data
- View own submissions

Cannot:

- Edit Quality
- Edit Engineering
- Edit Stores
- Manage users

==================================================

QUALITY_OPERATOR

Can:

- View Quality section
- Create/Edit Quality data
- View own submissions

Cannot:

- Edit Production
- Edit Engineering
- Edit Stores
- Manage users

==================================================

ENGINEERING_OPERATOR

Can:

- Update:
    - Downtime
    - Time Account
    - Energy
    - Stoppages

Cannot:

- Edit Production
- Edit Quality
- Edit Stores

==================================================

STORES_OPERATOR

Can:

- Update Materials
- Update Consumption

Cannot:

- Edit Production
- Edit Quality
- Edit Engineering

==================================================

MANAGER

Can:

- View EVERYTHING
- Review submissions
- Approve daily records
- Edit all operational sections

Cannot:

- Create system users
- Change system configuration

==================================================

ADMIN

Full access.

Can:

- Manage users
- Reset passwords
- Configure factory settings
- View audit logs
- Manage permissions
- Access all modules
